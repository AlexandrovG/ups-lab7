# Лабораторная работа №6 — исправления и порядок проверки

## Установка и запуск

Разместите каталоги `office-ups-sprint-6-backend` и `office-ups-frontend-sprint-6-redux-auth` рядом. В папке бэкенда:

1. Установите Go версии **1.27.1 или новее** (смотрите `go.mod`), Docker Desktop.
2. Создайте `.env` с локальными настройками (пароли ниже — только для локального учебного окружения):

```ini
DB_HOST=localhost
DB_PORT=5433
DB_USER=ups_user
DB_PASS=ups_password
DB_NAME=ups_office_db
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=redis_password
MINIO_ENDPOINT=localhost:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
MINIO_BUCKET_NAME=ups-media
JWT_SECRET=replace-with-long-random-string
JWT_EXPIRES_IN=24h
```

3. `docker compose up -d`.
4. Создайте bucket `ups-media` в консоли MinIO по адресу `http://localhost:9001` (пользователь minioadmin, пароль minioadmin); для браузерного просмотра учебных медиа разрешите анонимное скачивание объектов `ups-media` — **не выдавайте права на запись**.
5. `go run ./cmd/migrate` и `go run ./cmd/uninterruptible_power_supply_service` в отдельных запусках.
6. В соседней папке фронтенда: `npm install`, затем `npm run generate-api` (по локальному Swagger-файлу) и `npm run dev`; открыть `http://localhost:3000`.
7. Создайте пользователя `POST http://localhost:3000/api/auth/register` JSON `{"login":"student","password":"your-password"}`. Затем войдите через React.

## Настройка proxy

`vite.config.ts`: `/api` → `http://localhost:8080`, `/s3` → `http://localhost:9000` со снятием префикса `/s3`. Backend CORS middleware удалён: браузер взаимодействует только с origin фронтенда `localhost:3000`. Для медиа используйте `http://localhost:3000/s3/ups-media/имя_файла`.

## Обнаруженные и исправленные проблемы

- Удалена ненужная CORS-настройка на сервере.
- Добавлено поле `user_id` в ответ логина; раньше фронтенд сохранял `undefined` и мог считать ID NaN.
- Восстановлен маршрут `/login`, которого не было в `App.tsx`.
- Логин и выход — обычный Axios, авторизация передаёт Redux action вручную; logout отправляет Bearer JWT.
- Redux после F5 инициализируется как гость, токен в localStorage остаётся для учебной демонстрации; это **специальное требование лабораторной**, не рекомендуемая production-политика.
- Каталог и лента получают через открытый GET признак `is_creator` / `is_liked` при действительном Bearer JWT: необязательный auth middleware.
- Исправлены запросы с фильтрами ёмкости min/max через сгенерированный Axios API и Redux AsyncThunk.
- Mock используется только при недоступности API в гостевом режиме, без подмены ошибок для авторизованного пользователя.
- Кнопка «Создать и опубликовать» теперь вызывает два настоящих метода API через AsyncThunk, включая upload image/video.
- Лайк и удаление выполняют запросы на сервер; удаление доступно только владельцу карточки.
- Вывод медиа преобразован к S3 proxy; ошибки сохранения медиа больше не игнорируются обработчиками.
- Добавлена блокировка действий на время ряда AJAX-операций, обработка ошибок и единая цветовая палитра ИБП.
- Путь к Swagger-файлу в кодогенерации исправлен; создан ожидаемый `scripts/generate-api.mjs`.

## Проверка в браузере

Откройте DevTools → Network и отфильтруйте Fetch/XHR: запросы должны иметь Request URL `http://localhost:3000/api/...`; медиа — `http://localhost:3000/s3/ups-media/...`. В Redux DevTools покажите `auth` и `ups`. В Application → Local Storage сохранится `token`; после F5 в Redux `auth.isAuthenticated=false`. Для проверки `is_creator` сначала войдите, затем откройте Postman и передайте `Authorization: Bearer <token>` на **GET http://localhost:3000/api/uninterruptible-power-supplies** (не `http://localhost:8081`, где находится Adminer). Для проверки защищённого API в Postman можно использовать и `http://localhost:8080/api/...`.
