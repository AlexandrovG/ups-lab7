# ЛР №7 — короткий порядок работы

1. На ноутбуке: Docker → Go → React (`npm run dev`), убедись, что 5173 не занят Apache.
2. Сохрани старый проект. В новом: `npm ci`; для Pages: GitHub репозиторий с **содержимым папки фронтенда в корне** → Settings → Pages → GitHub Actions. Пуш в main запускает сборку mock + PWA.
3. На телефоне открой Pages, установи PWA, проверь фильтр 1400–2200, детали, возврат к каталогу, офлайн.
4. `mkcert` создать локальный сертификат на **реальный Wi-Fi IP**, импортировать только rootCA.pem в Android; `npm run build:lan` → `npm run serve:https`.
5. Открой `https://IP:8443` с телефона, войди под пользователем, покажи плитку, подробности, добавление и HTTPS.
6. Скриншоты 1–17 и все команды: `LAB7_WINDOWS_ИНСТРУКЦИЯ.md`. Deployment: `docs/lab7-deployment.png`.

ВАЖНО: Pages и LAN — разные сборки. Не публикуй `.env`, JWT, certs/*.pem или private keys.
